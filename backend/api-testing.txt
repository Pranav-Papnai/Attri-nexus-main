STEP 1: HEALTH CHECK (Check Server & Database Status)
================================================================================
Description: Verifies that backend server and MongoDB database are connected.

================================================================================
STEP 2: ADMIN LOGIN (Get Bearer JWT Token)
================================================================================
Description: Authenticates admin user and returns a 7-day JWT token.

POSTMAN / THUNDER CLIENT STEPS:
1. Select Method: POST
2. Enter URL: http://localhost:3001/api/auth/login
3. Click on the "Body" tab (next to Headers).
4. Select the "raw" radio button.
5. In the dropdown on the right, select "JSON".
6. Paste this JSON into the text box:
{
  "email": "admin@attrinexus.com",
  "password": "AttriAdmin2026!"
}
7. Click "Send" button.
8. COPY THE "token" STRING FROM THE RESPONSE TO USE IN NEXT STEPS.

EXPECTED STATUS: 200 OK
EXPECTED RESPONSE BODY:
{
  "success": true,
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "email": "admin@attrinexus.com",
    "name": "Attri Nexus Administrator",
    "role": "admin"
  }
}

TERMINAL / CURL COMMAND:
curl -X POST http://localhost:3001/api/auth/login \
  -H "Content-Type: application/json" \
  -d "{\"email\":\"admin@attrinexus.com\",\"password\":\"AttriAdmin2026!\"}"

STEP 3: GET CURRENT ADMIN PROFILE (/api/auth/me)
================================================================================

  }

TERMINAL / CURL COMMAND:
curl -X GET http://localhost:3001/api/auth/me \
  -H "Authorization: Bearer <YOUR_JWT_TOKEN>"


================================================================================
STEP 4: REGISTER NEW ADMIN USER (Admin Only)
================================================================================
Description: Creates another admin user (can only be called by an existing admin).

POSTMAN / THUNDER CLIENT STEPS:
1. Select Method: POST
2. Enter URL: http://localhost:3001/api/auth/register
3. Under "Authorization" tab -> Type: "Bearer Token" -> Paste your JWT token.
4. Click "Body" tab -> select "raw" -> select "JSON".
5. Paste this JSON:
{
  "email": "manager@attrinexus.com",
  "password": "ManagerPass2026!",
  "name": "Trade Desk Manager"
}
6. Click "Send" button.

EXPECTED STATUS: 201 Created
EXPECTED RESPONSE BODY:
{
  "success": true,
  "user": {
    "email": "manager@attrinexus.com",
    "name": "Trade Desk Manager",
    "role": "admin"
  }
}

TERMINAL / CURL COMMAND:
curl -X POST http://localhost:3001/api/auth/register \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <YOUR_JWT_TOKEN>" \
  -d "{\"email\":\"manager@attrinexus.com\",\"password\":\"ManagerPass2026!\",\"name\":\"Trade Desk Manager\"}"

STEP 10: UPDATE INQUIRY STATUS (Admin Only)
================================================================================
Description: Updates lead status ("new" -> "contacted" -> "quoted" -> "closed" -> "archived").

POSTMAN / THUNDER CLIENT STEPS:
1. Select Method: PATCH
2. Enter URL: http://localhost:3001/api/inquiries/<PASTE_INQUIRY_ID_FROM_STEP_9>/status
   (Example: http://localhost:3001/api/inquiries/674dfa12b890c123456789ab/status)
3. Under "Authorization" tab -> Type: "Bearer Token" -> Paste your JWT token.
4. Click "Body" tab -> select "raw" -> select "JSON".
5. Paste this JSON:
{
  "status": "contacted"
}
6. Click "Send" button.

EXPECTED STATUS: 200 OK
EXPECTED RESPONSE BODY:
{
  "success": true,
  "data": {
    "id": "674dfa12b890c123456789ab",
    "status": "contacted"
  }
}

TERMINAL / CURL COMMAND:
curl -X PATCH http://localhost:3001/api/inquiries/<INQUIRY_ID>/status \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <YOUR_JWT_TOKEN>" \
  -d "{\"status\":\"contacted\"}"
